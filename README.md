## 带宽和流量到底怎么算

按流量算一笔账更容易判断。10Mbps 满载跑一小时约 4.5GB，跑满一天就是 108GB。20Mbps 端口跑满，一天 216GB，1TB 月流量不到五天就用光。

反过来看，1TB 摊到 30 天，平均只能维持约 3.2Mbps 的持续输出。也就是说，如果你的业务是间歇性访问，比如网站、API、远程桌面，1TB 对 20Mbps 端口相当宽松；如果是 7×24 的持续传输、备份同步、下载中转，不限流量那一档才不会中途断掉。

这条换算比任何“不限流量”的宣传语都管用，也是 HK-VP01 和 HK-VP02 之间唯一需要想清楚的事。
